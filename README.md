# 📱 Spare Parts Ordering Application

A mobile application developed for **BAIT2073 Mobile Application Development** using Flutter and Dart. The application provides a platform for users to browse and order spare parts through a mobile interface.

This is a group assignment, and my individual contribution focuses on the **Delivery Confirmation** feature under the Order Delivery Module.

## 🎯 Project Objectives

- Develop a mobile application for spare parts ordering.
- Provide users with a convenient platform to purchase spare parts.
- Support the order delivery process.
- Implement delivery confirmation functionality.
- Improve the overall ordering and delivery experience.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Flutter | Mobile application development framework |
| Dart | Programming language |

## ⚙️ My Contribution – Delivery Confirmation

My individual responsibility was developing the **Delivery Confirmation** feature under the Order Delivery Module.

This feature focuses on confirming the delivery of customers' spare parts orders.

Key responsibilities include:

- Implementing the delivery confirmation functionality.
- Supporting the process of confirming order delivery.
- Displaying relevant delivery confirmation information.
- Integrating the feature into the overall Order Delivery Module.

## 🔄 Application Workflow

1. Users access the spare parts ordering application.
2. Users browse and select the spare parts they want to purchase.
3. Users proceed to place their orders.
4. The Order Delivery Module handles the delivery process.
5. The Delivery Confirmation feature supports the confirmation of delivered orders.
